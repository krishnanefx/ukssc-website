# UKSSC website — preview

A preview of the refreshed website for the **UKSSC** (United Kingdom-Singapore Students' Council), which represents, connects and empowers Singaporean students across the United Kingdom and Ireland.

**Preview:** https://krishnanefx.github.io/ukssc-website/

This repository holds the **built site only**: static HTML, CSS, JavaScript and images generated by [Astro](https://astro.build). The source is kept elsewhere, so don't edit these files by hand; rebuild from the source and replace them.

## How it's served

GitHub Pages serves the repository as it is, from `https://krishnanefx.github.io/ukssc-website/`. The `.nojekyll` file stops Pages from running Jekyll, which would otherwise drop the `_astro/` folder. Every page carries `noindex, nofollow`, so the preview stays out of search engines.

## Previewing locally

The site's links start with `/ukssc-website/`, so serve the folder *above* this one and open that path:

```sh
cd ..
python3 -m http.server 8000
# then open http://localhost:8000/ukssc-website/
```
